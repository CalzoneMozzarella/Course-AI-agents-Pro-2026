## Why

Студенти українських університетів потребують розумного помічника для швидкого пошуку актуальної інформації та формування корисних звітів. Ця зміна створює базового автономного агента на основі LangChain, який може самостійно отримувати поточний час, шукати свіжі дані в інтернеті та зберігати результати у структурованому вигляді для подальшого використання.

## What Changes

- Створення базового агента на основі `langchain_openai.ChatOpenAI` з моделлю `gpt-5-nano`.
- Реалізація трьох інструментів (tools):
  - `get_current_date`: Отримання поточної дати та часу.
  - `search_web`: Пошук інформації в інтернеті за допомогою DuckDuckGo.
  - `save_report`: Збереження результатів (topic, result, timestamp) у форматі JSON.
- Налаштування відповідного system prompt для української мови.
- Створення ланцюжка обробки запитів.

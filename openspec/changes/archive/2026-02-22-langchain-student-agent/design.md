## Context

Зміна впроваджує розробку агента-помічника для студентів на базі LangChain. Агент повинен мати здатність шукати свіжу інформацію за допомогою DuckDuckGo, отримувати поточну дату для розуміння контексту часу, а також зберігати звіт у форматі JSON. Це базовий проект, що демонструє використання інструментів (tools) у поєднанні з моделлю OpenAI (gpt-5-nano) та ланцюжком LangChain (chain).

## Goals / Non-Goals

**Goals:**

- Реалізувати три інструменти (tools): `get_current_date`, `search_web`, `save_report`.
- Налаштувати `ChatOpenAI` з моделлю `gpt-5-nano` або подібною.
- Налаштувати `system_prompt` для роботи українською мовою.
- Зв'язати промпт, модель та парсер за допомогою LangChain Expression Language (LCEL).
- Успішно виконати запит та зберегти результати у JSON-файл з полями: `topic`, `result`, `timestamp`.

**Non-Goals:**

- Створення повноцінного веб-інтерфейсу або Telegram-бота (лише консольний скрипт).
- Використання складної пам'яті (Memory) для ведення довгих діалогів.
- Реалізація інших інструментів, окрім трьох зазначених.

## Decisions

- **Фреймворк:** Використовується LangChain (`langchain`, `langchain-openai`, `langchain-core`), оскільки він надає зручний інтерфейс для роботи з LLM та інструментами.
- **Пошукова система:** DuckDuckGo (`duckduckgo-search`) обрано як безкоштовний варіант без необхідності отримання додаткових API-ключів, на відміну від Google Custom Search або Bing Search.
- **Формат збереження:** Звіти зберігатимуться у `JSON` через його структурованість та легкість парсингу (міститиме `topic`, `result` та `timestamp`). Для забезпечення надійності буде використано стандартну бібліотеку `json`.
- **Спосіб підключення інструментів:** Оскільки це базовий ланцюжок (chain), а не повноцінний Agent Executor (хоча в завданні згадується "агент"), інструменти можуть бути прив'язані до LLM за допомогою `llm.bind_tools()`, або викликатися явно в коді, якщо використовується звичайний chain (`prompt | llm | parser`). Для виконання вимог завдання (агент), доцільно використовувати `create_tool_calling_agent` або `bind_tools` у поєднанні зі звичайним викликом.

## Risks / Trade-offs

- **[DuckDuckGo Rate Limits]** → Бібліотека `duckduckgo-search` може зіткнутися з лімітами на кількість запитів. Мітигація: у разі помилки додавати обробку виключень або затримки (sleep).
- **[Парсинг результатів JSON]** → Формування звіту з LLM може іноді містити некоректний JSON. Мітигація: використовувати Pydantic Output Parser або передавати збереження звіту як інструмент (`save_report`), який LLM викликає самостійно за потреби, що є більш надійним.
